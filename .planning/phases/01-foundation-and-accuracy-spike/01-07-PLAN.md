## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| People to repository | Teammates' body measurements are typed into tracked files |
| Phone to dev server | Real phones load the app over the LAN with a self-signed certificate |
| Human-reported results to project record | Results typed by hand become the evidence for the go/no-go |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-35 | Information disclosure | Subject identity or images in the repository | mitigate | IDs S1 to S9 enforced by `report.mjs --check`; Task 3 verify fails if any image or video is tracked under `validation/`; the ID key and consent stay outside the repository (PROTOCOL.md) |
| T-01-36 | Information disclosure | Camera frames leaving the device during a real scan | mitigate | Task 2 step 4: network and storage check with developer tools on every device, result recorded under PRIV-02 |

| T-01-38 | Tampering | Readings invented, rounded or adjusted by the executor | mitigate | Task 2 and Task 3 actions forbid entering anything the human did not supply; rows are appended exactly as given |
