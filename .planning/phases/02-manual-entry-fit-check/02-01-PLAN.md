    - Borderline: recommended ease - min <= BORDERLINE_BAND_CM => borderline, neighbour = next larger size (if any); or min - previous size ease <= BORDERLINE_BAND_CM => borderline, neighbour = previous size. Body 85.5 regular: XS ease 8.5 -> XS, borderline, neighbour "S".
    - Body larger than XL needs: label null, outOfRange "above".
    - Regular preference agrees with sizeFromBust(chestCm, PLAIN_TEE).label for chest 70..86 (loop test) whenever not out of range.
    - checkFit with body 80, size "XS", regular: chest ease 14 inside [8,16] -> ok, diffCm 0. Size "XL": ease 30 -> loose, diffCm +14 (beyond window max 16). Body 90, size "XS": ease 4 -> tight, diffCm -4.
    - Area status borderline flag: status ok but within 1 cm of a window edge.
    - Verdict: any tight -> "too-small"; else any loose -> "too-large"; else any ok-with-borderline -> "borderline"; else "fits". Tight wins over loose.
    - recommendAll(chestCm, chart) -> { regular, loose, oversize } each a recommendSize result.
