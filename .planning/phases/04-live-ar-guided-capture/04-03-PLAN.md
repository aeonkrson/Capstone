Decisions:
- P4-D10: Cues are synthesized with OscillatorNode + GainNode (short attack/release ramps to avoid clicks). Patterns (frequency Hz, duration s, gap 0.08 s between tones):
  - hold: one tone 660 for 0.15
  - captured: 880 for 0.12 then 1320 for 0.2 (rising)
  - turn: 523 for 0.18, 523 for 0.18, 392 for 0.35 (two same then lower)
  Sine wave, peak gain 0.3. Values in one frozen CUES object.
- P4-D11: The AudioContext is created and resumed in `unlock()`, which the app calls from the consent Accept click (iOS and Chrome autoplay rules need a user gesture). Before unlock, or when no AudioContext constructor exists, `play` does nothing and never throws.
- P4-D12: Globals are read lazily through an injectable constructor (default `globalThis.AudioContext || globalThis.webkitAudioContext`), same pattern as createTiltSensor, so the module imports in Node.
- P4-D13: The pose guide is a stick figure (head circle plus line segments) drawn in canvas pixels, body from 8% to 92% of canvas height, centred horizontally. Front: shoulders and hips wide, arms angled about 20 degrees out from the body, legs slightly apart. Side: narrow torso, arms straight down, legs together. Pure geometry in src/core so it is unit tested; drawing happens in src/ui (plan 04-07).

<interfaces>
Contract this plan creates:
- src/platform/sound.js:
  - `export const CUES` frozen: `{ hold: [[660, 0.15]], captured: [[880, 0.12], [1320, 0.2]], turn: [[523, 0.18], [523, 0.18], [392, 0.35]] }` (each entry [hz, seconds]).
  - `export function createSound({ AudioContextCtor = globalThis.AudioContext || globalThis.webkitAudioContext } = {})` returns `{ unlock(): Promise<boolean>, play(name): void, close(): void }`.
  - `play` queues: each cue starts at max(ctx.currentTime, end of the previously scheduled cue + 0.15 s), scheduled on the AudioContext clock, no setTimeout. So play("captured") then play("turn") in the same tick are heard one after the other, never overlapping.
  - Unknown cue names are ignored. Any thrown error inside is caught and logged with console.error("Sound cue failed:", err).
- src/core/poseGuide.js:
  - `export function guideFigure(view, width, height)` returns `{ head: { cx, cy, r }, segments: Array<[x1, y1, x2, y2]> }` in canvas px. Throws on view other than "front" or "side".
