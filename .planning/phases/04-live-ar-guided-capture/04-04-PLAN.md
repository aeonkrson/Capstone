Decisions:
- P4-D14: The controller does not own the scan session or the camera. It receives `capture(view)` (returns a Promise of a runBurst-shaped result; the app records it into the session) and `cue(name)` (the app plays sound). This keeps it testable and keeps Phase 3 burst code unchanged.
- P4-D15: The controller does not await capture inside onFrame. While a capture runs, stepLock is in "capturing" and frames are ignored by the reducer. A generation counter drops results that arrive after stop() or restart().
- P4-D16: Live frames must carry a mask for checkFrame; the app passes `wantMask: true` while the guided scan is active (plan 04-07). Device pitch comes from the tilt sensor via the onFrame argument.

<interfaces>
From src/core/autoLock.js (plan 04-01): `initialLock()`, `stepLock(state, event)` -> `{ state, cues, action }`, `bodyAnchors(lm)`, `lockMessageKey(state)`. Events: frame `{ type: "frame", t, gate, anchors }`, `{ type: "capture-done", t, view, ok, reason }`, `{ type: "restart" }`.
From src/core/quality.js: `checkFrame(obs, view, { devicePitchDeg })`.
runBurst result shape: `{ ok: true, ... }` or `{ ok: false, code, reason? }`.

Contract this plan creates:
- `export function createGuidedScan({ capture, cue = () => {}, onChange = () => {}, now = () => performance.now() })` returns:
  - `start()`: active = true, state = initialLock(), onChange(status()).
  - `stop()`: active = false, bumps generation, onChange(status()).
  - `restart()`: stepLock restart event, bumps generation, active = true, onChange.
  - `onFrame(obs, tMs, devicePitchDeg = null)`: no-op when inactive or when the current phase is "capturing" or "done"; else view = state.view, gate = checkFrame(obs, view, { devicePitchDeg }), anchors = gate.ok ? bodyAnchors(obs.lm) : null, applies stepLock. Returns status().
  - `status()`: `{ active, phase, view, hint, messageKey: lockMessageKey(state), gateOk }` where gateOk is the last frame's gate.ok (false before any frame).
  - Applying a step: for each cue call cue(name); if action, call capture(action.view) and on settle (resolve or reject) feed `{ type: "capture-done", t: now(), view, ok: result.ok === true, reason: result.reason ?? result.code ?? null }` (reason "aborted" stays "aborted"; rejection -> ok false, reason null, console.error("Guided capture failed:", err)) unless the generation changed. onChange(status()) after every state change.
- `performance` is allowed in src/app (core purity only covers src/core); the default `now` is only read when called.
</interfaces>
