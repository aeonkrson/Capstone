# Project File Documentation

The GreenWear prototype was removed on 2026-10 and remains in git history. This document describes the Size Fit Scanner layout.

## Top level

- `index.html` - page shell with a strict Content-Security-Policy and no third-party scripts.
- `css/style.css` - styles for the shell, camera panel and HUD.
- `package.json`, `package-lock.json` - scripts (`dev`, `build`, `demo`, `test`, `vendor`, `vendor:check`) and pinned dev dependencies.
- `vite.config.js` - Vite config with the HTTPS plugin.
- `README.md` - run, demo runbook, tests, privacy, study.
- `HUMAN-TODO.md` - every outstanding human step, in order.
- `FILES.md` - this file.
- `CLAUDE.md` - project instructions for the coding agent.
- `.planning/` - project planning notes (not served by the dev server).
- `recordings/` - gitignored folder for the fallback demo video (created by hand; never committed).

## src/

- `src/main.js` - entry module loaded by the page.
- `src/core/` - pure measurement and fit logic, no browser globals, testable in Node (scan, quality, auto-lock, calibration, fit, profile state, preflight, frame rate).
- `src/platform/` - adapters for camera, pose detection, frame loop, sound, tilt and storage.
- `src/app/` - orchestration between platform adapters and core logic (guided scan, burst, scan session, fit app).
- `src/ui/` - DOM and canvas rendering (consent, scan, guide, review, profile, catalog, fit, settings, debug).
- `src/data/` - static data such as garment size charts and the catalog.
- `src/i18n/` - English and Indonesian string dictionaries.

## Other folders

- `vendor/mediapipe/` - self-hosted, version-pinned body detection files and their SHA-256 hashes.
- `scripts/vendor-mediapipe.mjs` - downloads and checks the pinned detection files.
- `scripts/copy-vendor-to-dist.mjs` - after `vite build`, copies the detection files into `dist/vendor/mediapipe/` and checks their hashes.
- `test/` - Node built-in test runner tests.
- `dist/` - build output (gitignored).

## validation/

- Protocols and checklists: `PROTOCOL.md`, `DEFINITIONS.md`, `PASS-CRITERIA.md`, `DEVICE-CHECKLIST.md`, `GARMENT-CHECK.md`, `FLOW-CHECKLIST.md`, `STUDY-PROTOCOL.md`, `DEMO-RECORDING.md`.
- Records: `GO-NO-GO.md`, `PHASE3-RESULTS.md`, `STUDY-RESULTS.md` (generated by `study.mjs --write`, not edited by hand).
- Data: `readings.csv` (Phase 1), `phase3-readings.csv` (Phase 3), `study-readings.csv` (Phase 5).
- Scripts: `report.mjs`, `calibrate.mjs`, `study.mjs`.
