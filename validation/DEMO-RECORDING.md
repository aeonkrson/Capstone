# Fallback demo recording

A short video to play if the live demo fails (no camera, no network, no HTTPS).

Status: Recorded: not yet

## Rules

- Record the laptop screen and one phone screen with the OS screen recorder.
- Only record a consenting team member in everyday clothes.
- Store the file in `recordings/` (gitignored) or on a USB drive and a cloud drive outside the repo. Never commit it.
- Length target: 2 to 3 minutes.
- Check the file plays offline on the demo laptop.

## Shot list (in order)

1. Open the HTTPS address from `npm run demo`.
2. Consent screen.
3. Guided scan, front then side, with sound on.
4. Review screen, edit one value.
5. Fit verdict.
6. Compare table.
7. History.
8. Scan again.
9. Language switch.
10. Manual entry path.

## Narration notes

English: say what the screen is for in one sentence, then what you do. Mention that images and measurements stay on the device.

Indonesian: sebutkan fungsi layar dalam satu kalimat, lalu apa yang dilakukan. Sebutkan bahwa gambar dan ukuran tubuh tetap berada di perangkat.
